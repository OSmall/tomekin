# Tomekin glossary map

Use this map to select the domain documentation relevant to a change.

- [`GLOSSARY.md`](GLOSSARY.md) is the current shared Tomekin glossary. It covers the collection-first deck-building
  domain

## Package contexts

The workspace packages currently use the shared glossary and
system-wide ADRs. Add a package-local `GLOSSARY.md` and `docs/adr/` only when a package develops language or decisions
that are not shared across the workspace.
